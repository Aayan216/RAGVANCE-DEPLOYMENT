# RAGVANCE — Deployment

Production deployment repository for **RAGVANCE — AI Study Assistant**.

The main project, documentation, features, architecture, setup, tests, and development details are maintained in the original repository:

urlRAGVANCE — Main Repositoryhttps://github.com/Aayan216/RAGVANCE

This repository contains the deployment-specific version used for production hosting.

## Deployment

- **Platform:** Render
- **Database:** Supabase PostgreSQL
- **File Storage:** Supabase Storage
- **Vector Store:** FAISS
- **AI:** Google Gemini
- **Production Embeddings:** ONNX Runtime

The deployment repository is intentionally kept separate from the development repository so production-specific configuration can be maintained independently.

## Status

Production deployment is currently active and tested.
